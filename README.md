# Phamento
A website I created in 2022 for my friend's bubble tea business. This app was created in vanilla Node.js and features localization without the help of a third party library. Styling was also done from scratch without a third party library.

## Build and Run
First, clone this repository from a terminal:
```
git clone https://github.com/corbinedwards/phamento.git
```

Next, install NPM packages from within the `/phamento` directory:
```
npm i
```

Then run the app:
```
npm run start
```

Lastly, visit `localhost:3000` in a web browser.
